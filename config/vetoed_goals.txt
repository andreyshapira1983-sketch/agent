# Цели, которые агент брать не должен. Пишет сюда только человек.
#
# Одна строка — один отзыв. Можно писать целиком цель, а можно только предмет
# работы (путь к файлу) — тогда отзывается любая цель об этом предмете.
# Строка, начинающаяся с #, и пустая строка ничего не отзывают.
#
# Отзыв действует немедленно и бессрочно: выбор цели проверяет этот список
# перед каждой кампанией и отказывается с названной причиной.
# Чтобы вернуть цель — удалите строку.
#
# Пример:
#   core/model_router.py
#   Переписать экономику агента целиком
#
# Файл живёт в config/ намеренно: сюда не дотягивается ни уборка памяти, ни
# лента самоправки, поэтому агент не может отменить отзыв сам.
